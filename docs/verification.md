# 検証記録

## ローカル検証

- アルゴリズム最小テスト: `node --test tests/core.test.mjs`、9件成功。
- Chrome実ブラウザ自動操作: `node tests/browser.mjs`、12項目成功。学習開始・停止（停止後世代不変）、一世代、seed初期化と進化の再現性、リプレイ、ライブ中間出力と制御計算の一致、ドラッグ、配置復元、390pxタッチでの選択→タップ移動、スマホ操作、横溢れなし。console error / pageerror 0件。
- 初期seed `ALPHA-2016` の実測: 世代0は平均573.5928点・3/3到達、世代12は平均579.9007点・3/3到達。初期個体がすでに到達できたため、主に時間・経路が改善した結果であり、到達率が上がったという主張ではない。
- 世代12で障害物1を `(130,270)` に移動: 学習配置は3/3到達のまま、編集した評価配置では0/3到達。未知配置の失敗を表示していることを確認。
- デスクトップ1440px、モバイル390pxのスクリーンショットを保存。

## 回帰防止の負例検証

修正を一つずつ意図的に巻き戻し、同じブラウザテストが実際に失敗することを確認してから、修正を復元し再実行した。

1. 初期化順序を巻き戻すと `evo.generation` の未初期化参照でブラウザ起動テストが失敗。
2. リプレイの制御表示を固定した飛行個体でなく最新学習個体で計算する状態へ巻き戻すと、ライブ中間出力の一致検査が失敗。

復元後、9件のアルゴリズムテストと12項目のブラウザ検証が再度成功。

## 制約

固定配置・3初期向きによる小規模な最適化であり、厳密な未知分布のベンチマークではない。機体の飛行は簡略2Dモデル。実スマホ端末ではなくChromeの390pxタッチエミュレーション。ブラウザの負荷次第で世代更新速度は変わるが、乱数系列とシミュレーションは描画速度に依存しない。実行時の追加依存なし。
